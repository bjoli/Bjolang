#+TITLE: Slow tests

Tests too slow or too broad for ~run_tests.py~: randomized runs against a
model, many sizes, many key types. ~run_tests.py~ does not run them.

#+BEGIN_SRC sh
bjo test tests/collections/*.bjo
#+END_SRC

- ~collections/~: the persistent collections of the standard library, each
  against a reference array: ~Vec~, ~Map~, ~(std hashset)~,
  ~(std orderedmap)~ and ~(std orderedset)~. Run them after a change to one
  of them, or to the nodes in ~BjolangRuntime/Rrb~, ~BjolangRuntime/HashTries~
  or ~BjolangRuntime/OrderedTrees~.
- Each file is a program using ~(std simpletest)~. A failed check prints
  ~FAILURE:~ and makes the program exit 1, which ~bjo test~ reports.
- Build ~std~ first (~./build_std.sh~): the tests use the built library.
