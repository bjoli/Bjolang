#+TITLE: Slow tests

Tests too slow or too broad for ~run_tests.py~: randomized runs against a
model, many sizes, many key types. ~run_tests.py~ does not run them.

#+BEGIN_SRC sh
bjo test tests/collections/*.bjo tests/unicode/*.bjo
#+END_SRC

- ~collections/~: the persistent collections of the standard library, each
  against a reference array: ~Vec~, ~Map~, ~(std hashset)~,
  ~(std orderedmap)~ and ~(std orderedset)~. Run them after a change to one
  of them, or to the nodes in ~BjolangRuntime/Rrb~, ~BjolangRuntime/HashTries~
  or ~BjolangRuntime/OrderedTrees~.
- ~unicode/~: ~(std unicode grapheme)~ on random text of the characters the
  rules treat differently, as strings and as texts of many chunks. Run it
  after a change to the rules, the table, or the text front end.
- ~contexts/contexts.fsx~: the contexts of ~Compilation.fs~. An F# script
  that loads the compiler: ~dotnet fsi --quiet tests/contexts/contexts.fsx~.
  It checks every file of ~TestFiles/errors~ one at a time and then on 8 and
  16 threads, and compares what each check gives. Run it after a change to
  the state that a module of the compiler keeps. About a minute.
- Each file is a program using ~(std simpletest)~. A failed check prints
  ~FAILURE:~ and makes the program exit 1, which ~bjo test~ reports.
- Build ~std~ first (~./build_std.sh~): the tests use the built library.
