* std/run — running programs

#+BEGIN_SRC scheme
(import (std run))

(run/string '(pipe (cat "hej.txt") (wc -l)))
(run/status '(into-file "out.txt" (from-file "in.txt" (pipe (grep "x") sort))))
#+END_SRC

A *form* is one thing to run, written as a quoted literal.

** The grammar

| ~'(cat "hej.txt")~                    | run a program                        |
| ~'(sort)~, or ~sort~ in a pipe        | one taking no arguments              |
| ~'(pipe (cat "a") (wc -l))~           | connect them                         |
| ~'(from-file "in.txt" (wc -l))~       | stdin from a file                    |
| ~'(into-file "out.txt" (ls))~         | stdout to a file, truncating         |
| ~'(append-to-file "log" (date))~      | stdout to a file, appending          |
| ~'(errors-into-file "e" (make))~      | stderr of every command inside       |
| ~'(errors-append-to-file "e" (make))~ | the same, appending                  |
| ~'(,(cmd program "-l"))~              | a computed program name              |
| ~'(pipe (cat "x") ,my-filter)~        | a stage written in Bjolang           |
| ~'(grep ["-i" "bomb"])~               | splice a computed argv               |
| ~'("pipe" "-x")~                      | the *program* called ~pipe~          |

Redirections nest:
~(into-file "out" (from-file "in" (pipe (tr "a" "b") sort)))~.

~pipe~, ~from-file~ and the rest are tags: the head of a form names its case,
and the name, the arity and every argument are checked at compile time. A head
that names no tag is a command.

A word is a symbol, string, int, double, ~[...]~ argv vector, nested form,
unquoted ~Cmd~ or unquoted ~Filter~ — eight cases, and nothing else. A
character is a type error where it is written.

** Types

- ~Form~ : a command, a pipeline, a redirection, or one bare stage.
- ~Word~ : one word of a command.
- ~Cmd~ : a command and its arguments, built by ~cmd~.
- ~Filter~ : ~(-bjo-> TextInputPort TextOutputPort Unit)~. A stage written in
  Bjolang: read ~in~ to its end, write to ~out~, return. A ~defbjo~, so it may
  ~sync~. *Do not close ~out~* — ~run~ does that when you return.
- ~(Reader %a)~ : ~(-bjo-> TextInputPort (Chan %a) Unit)~. How ~run/channel~
  turns output into items.
- ~Proc~ : a started form. Opaque.

** Blocking, from an ordinary function

- ~(run/string form)~ : ~(Result Exception string)~ — stdout.
- ~(run/strings form)~ : ~(Result Exception (Vec string))~ — the same, by line.
- ~(run/status form)~ : ~(Result Exception int)~ — drains stdout, keeps the code.
- ~(run/output form)~ : ~(Result Exception (Tuple int string))~ — the code and stdout.
- ~(run form)~ : ~(Result Exception Proc)~ — starts it; both ends are yours.
- ~(cmd prog arg ...)~ : a ~Cmd~, for ~,(cmd ...)~ in a form.

** A running form

- ~(proc-input p)~ : ~(Option TextOutputPort)~ — write here; ~None~ after a ~from-file~.
- ~(proc-output p)~ : ~(Option TextInputPort)~ — read here; ~None~ after an ~into-file~.
- ~(wait p)~ : ~(Result Exception int)~ — blocks. The last command's code, or ~0~.
- ~(wait/all p)~ : ~(Result Exception (Vec int))~ — every code, in start order.
- ~(kill p)~ : stop everything.

** From inside a bjoroutine

#+BEGIN_SRC scheme
(match (run/channel '(cat "log.txt") by-lines)
  ((Err e) 0)
  ((Ok (Tuple items p))
   (let go ((n 0))
     (match (sync (choose (wrap (chan-recv items) (fun (line) (Got line)))
                          (wrap (exited p)        (fun (r) Ended))))
       ((Got line) (go (+ n 1)))
       (Ended n)))))
#+END_SRC

Blocking parks a pool thread the fibers need.

- ~(exited p)~ : ~(Event (Result Exception int))~ — on exit. Observes only.
- ~(running form)~ : ~(Event (Result Exception string))~ — a whole form as one
  event. Owns it: starts on arrival, kills the loser.
- ~(run/channel form reader)~ : ~(Result Exception (Tuple (Chan %a) Proc))~ —
  output as items. The reader is a stage, so ~exited~ covers it.
- ~by-lines~ : the stock ~(Reader string)~, one item per line.

** Scoped

- ~(with-run (name form) body ...)~ — runs ~form~ for the body and kills it on
  the way out. ~name~ is the ~(Result Exception Proc)~. A macro, so the body may ~sync~.

** Gotchas

- Close the input, and drain the output, or the first stage never sees EOF and
  ~wait~ never returns.
- A form is one thing: ~'((cat "a") (wc -l))~ is refused — say ~pipe~.
- A bare tag in stage position is a type error; ~'("into-file" ...)~ is the
  program of that name.
- Piping out of a redirect, or redirecting an end twice, is refused.
- After ~into-file~, ~run/string~ gives ~""~ — use ~run/status~.
- stderr is inherited unless ~errors-into-file~ says otherwise.
- A filter must not close its output port, and a raising one surfaces through
  ~wait~ rather than as an exit code.
- Blocking entry points inside a bjoroutine park a pool thread — use ~exited~ /
  ~running~ / ~run/channel~, or ~(blocking ...)~.
- One word is one argument, spaces and all; doubles render invariantly.
